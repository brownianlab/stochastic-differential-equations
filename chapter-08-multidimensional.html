Chapter 8 — Multi-Dimensional Itô Calculus

Guiding question

Most real financial systems involve many correlated assets. How does Itô calculus extend to vector-valued processes, and what role does the correlation matrix play? When does correlation create new drift terms?

Every multi-asset model — baskets, spreads, rainbow options, cross-currency products — requires understanding how correlated Brownian motions interact. The key new object is the cross-variation d[Wi,Wj]=ρij dtd[W^i, W^j] = \rho_{ij}\,dtd[Wi,Wj]=ρij​dt, which encodes how randomness in one dimension influences another.

8.1 Multi-dimensional Brownian motion​

A ddd-dimensional standard Brownian motion is a vector process Wt=(Wt1,…,Wtd)\mathbf W_t = (W_t^1,\ldots,W_t^d)Wt​=(Wt1​,…,Wtd​) where:

  1. Each WtiW_t^iWti​ is a one-dimensional Brownian motion.
  2. The components are independent: Wti−WsiW_t^i - W_s^iWti​−Wsi​ is independent of Wtj−WsjW_t^j - W_s^jWtj​−Wsj​ for i≠ji\ne ji=j.
  3. W0=0\mathbf W_0 = \mathbf 0W0​=0.

For a correlated ddd-dimensional Brownian motion with correlation matrix ρ=(ρij)i,j=1d\rho = (\rho_{ij})_{i,j=1}^dρ=(ρij​)i,j=1d​, write

Wt=BtΣ1/2,\mathbf W_t = \mathbf B_t\Sigma^{1/2},Wt​=Bt​Σ1/2,

where Bt\mathbf B_tBt​ is a standard ddd-dimensional BM and Σ1/2\Sigma^{1/2}Σ1/2 is the Cholesky factor of the correlation matrix ρ\rhoρ (so (Σ1/2)(Σ1/2)⊤=ρ(\Sigma^{1/2})(\Sigma^{1/2})^\top = \rho(Σ1/2)(Σ1/2)⊤=ρ).

The defining properties of correlated BM are:

Cov(Wti,Wtj)=ρij t,d[Wi,Wj]t=ρij dt.\text{Cov}(W_t^i, W_t^j) = \rho_{ij}\,t, \qquad d[W^i,W^j]_t = \rho_{ij}\,dt.Cov(Wti​,Wtj​)=ρij​t,d[Wi,Wj]t​=ρij​dt.

8.2 Constructing correlated BM from independent BM​

Given independent BMs Z1,…,ZdZ^1,\ldots,Z^dZ1,…,Zd and a correlation matrix ρ\rhoρ with Cholesky decomposition ρ=LL⊤\rho = LL^\topρ=LL⊤, set:

Wti=∑jLijZtj.W_t^i = \sum_j L_{ij}Z_t^j.Wti​=j∑​Lij​Ztj​.

Then

d[Wi,Wj]=∑kLik dZk ∑ℓLjℓ dZℓ=∑kLikLjk dt=(LL⊤)ij dt=ρij dt.d[W^i,W^j] = \sum_k L_{ik}\,dZ^k\,\sum_\ell L_{j\ell}\,dZ^\ell = \sum_k L_{ik}L_{jk}\,dt = (LL^\top)_{ij}\,dt = \rho_{ij}\,dt.d[Wi,Wj]=k∑​Lik​dZkℓ∑​Ljℓ​dZℓ=k∑​Lik​Ljk​dt=(LL⊤)ij​dt=ρij​dt.
Correlated Brownian motions: dW₁dW₂ = ρ dt
Cross-variation ⟨W¹,W²⟩_T ≈0.7012 (theory: 0.70)
Covariation ruledW¹dW² = ρ dt
When ρ = 1 the two paths are identical; ρ = 0 gives independent paths; ρ = −1 gives mirror paths. The scatter ellipse tilts with ρ, geometrically encoding the covariance. This bivariate structure underpins basket options, spreads, and correlated rate models.

8.3 The multi-dimensional Itô formula​

Let Xt=(Xt1,…,Xtn)\mathbf X_t = (X_t^1,\ldots,X_t^n)Xt​=(Xt1​,…,Xtn​) be a vector of Itô processes:

dXti=bti dt+∑j=1dσtij dWtj,i=1,…,n.dX_t^i = b_t^i\,dt + \sum_{j=1}^d \sigma_t^{ij}\,dW_t^j, \qquad i=1,\ldots,n.dXti​=bti​dt+j=1∑d​σtij​dWtj​,i=1,…,n.

The quadratic (co-)variation is:

d[Xi,Xj]t=∑k=1dσtikσtjk dt=(σσ⊤)ij dt=:ctij dt.d[X^i,X^j]_t = \sum_{k=1}^d\sigma_t^{ik}\sigma_t^{jk}\,dt = (\sigma\sigma^\top)_{ij}\,dt =: c_t^{ij}\,dt.d[Xi,Xj]t​=k=1∑d​σtik​σtjk​dt=(σσ⊤)ij​dt=:ctij​dt.
Multi-dimensional Itô formula

For f∈C1,2([0,T]×Rn)f\in C^{1,2}([0,T]\times\mathbb R^n)f∈C1,2([0,T]×Rn),

df(t,Xt)=∂tf dt+∑i∂if dXti+12∑i,j∂ijf d[Xi,Xj]t.df(t,\mathbf X_t) = \partial_t f\,dt + \sum_i \partial_i f\,dX_t^i + \tfrac12\sum_{i,j}\partial_{ij}f\,d[X^i,X^j]_t.df(t,Xt​)=∂t​fdt+i∑​∂i​fdXti​+21​i,j∑​∂ij​fd[Xi,Xj]t​.

Expanded:

df(t,Xt)=[∂tf+∑ibti∂if+12∑i,jctij∂ijf]dt+∑i,kσtik∂if dWtk.df(t,\mathbf X_t) = \left[\partial_t f + \sum_i b_t^i\partial_i f + \tfrac12\sum_{i,j}c_t^{ij}\partial_{ij}f\right]dt + \sum_{i,k}\sigma_t^{ik}\partial_i f\,dW_t^k.df(t,Xt​)=[∂t​f+i∑​bti​∂i​f+21​i,j∑​ctij​∂ij​f]dt+i,k∑​σtik​∂i​fdWtk​.
The Hessian and the diffusion matrix

The second-order term 12∑i,jcij∂ijf\frac12\sum_{i,j}c^{ij}\partial_{ij}f21​∑i,j​cij∂ij​f is the contraction of the Hessian ∇2f\nabla^2 f∇2f with the diffusion covariance matrix c=σσ⊤c = \sigma\sigma^\topc=σσ⊤. In geometric terms, this is the trace of the product c⋅∇2fc\cdot\nabla^2 fc⋅∇2f. The Laplacian Δf\Delta fΔf corresponds to c=Ic = Ic=I (isotropic diffusion). Anisotropic diffusion — different volatilities and correlations — creates a non-isotropic "heat" operator.

8.4 The Itô multiplication table in ddd dimensions​

The extended multiplication table for correlated BMs (dWti dWtj=ρij dt)(dW^i_t\,dW^j_t = \rho_{ij}\,dt)(dWti​dWtj​=ρij​dt):

dWidW^idWidtdtdt
dWjdW^jdWjρij dt\rho_{ij}\,dtρij​dt000

For uncorrelated components (i≠ji\ne ji=j, ρij=0\rho_{ij}=0ρij​=0): dWi dWj=0dW^i\,dW^j = 0dWidWj=0. Cross terms vanish, and Itô's formula simplifies to the sum of independent one-dimensional formulas.

8.5 Key example: the log of a basket​

Let St1,…,StnS_t^1,\ldots,S_t^nSt1​,…,Stn​ follow correlated GBMs:

dSti=μiSti dt+σiSti dWti,d[Wi,Wj]=ρij dt.dS_t^i = \mu_i S_t^i\,dt + \sigma_i S_t^i\,dW_t^i, \qquad d[W^i,W^j] = \rho_{ij}\,dt.dSti​=μi​Sti​dt+σi​Sti​dWti​,d[Wi,Wj]=ρij​dt.

The log of the basket Bt=∑iwiStiB_t = \sum_i w_i S_t^iBt​=∑i​wi​Sti​ (equal weights wi=1/nw_i = 1/nwi​=1/n) satisfies:

dBt=∑iwi dSti=(∑iwiμiSti)dt+∑iwiσiSti dWti.dB_t = \sum_i w_i\,dS_t^i = \left(\sum_i w_i\mu_i S_t^i\right)dt + \sum_i w_i\sigma_i S_t^i\,dW_t^i.dBt​=i∑​wi​dSti​=(i∑​wi​μi​Sti​)dt+i∑​wi​σi​Sti​dWti​.

The variance of dBt/BtdB_t/B_tdBt​/Bt​ is (locally):

σbasket2 dt=1Bt2∑i,jwiwjσiσjρijStiStj dt.\sigma_{\text{basket}}^2\,dt = \frac{1}{B_t^2}\sum_{i,j}w_i w_j\sigma_i\sigma_j\rho_{ij}S_t^i S_t^j\,dt.σbasket2​dt=Bt2​1​i,j∑​wi​wj​σi​σj​ρij​Sti​Stj​dt.

This formula shows that correlation reduces basket volatility: when ρij<1\rho_{ij} < 1ρij​<1, the basket is less volatile than any single component.

8.6 Correlated Black–Scholes: two assets​

For two correlated assets S1,S2S^1, S^2S1,S2 with correlation ρ\rhoρ, the joint risk-neutral dynamics are:

dSt1=rSt1 dt+σ1St1 dWt1,dSt2=rSt2 dt+σ2St2(ρ dWt1+1−ρ2 dWt2),dS_t^1 = rS_t^1\,dt + \sigma_1 S_t^1\,dW_t^1, \qquad dS_t^2 = rS_t^2\,dt + \sigma_2 S_t^2(\rho\,dW_t^1 + \sqrt{1-\rho^2}\,dW_t^2),dSt1​=rSt1​dt+σ1​St1​dWt1​,dSt2​=rSt2​dt+σ2​St2​(ρdWt1​+1−ρ2​dWt2​),

where W1,W2W^1,W^2W1,W2 are independent BMs under Q\mathbb QQ. The correlation structure enters through the ρ dW1\rho\,dW^1ρdW1 term in S2S^2S2's dynamics.

The covariance matrix of the log-returns over [0,T][0,T][0,T] is:

Σ=T(σ12ρσ1σ2ρσ1σ2σ22).\Sigma = T\begin{pmatrix}\sigma_1^2 & \rho\sigma_1\sigma_2\\ \rho\sigma_1\sigma_2 & \sigma_2^2\end{pmatrix}.Σ=T(σ12​ρσ1​σ2​​ρσ1​σ2​σ22​​).
Correlation in options: dispersion trading

When correlation ρ\rhoρ decreases, basket options become cheaper relative to individual options. Dispersion traders sell basket variance and buy individual variance, profiting when realized correlation is lower than implied correlation.

The key formula: σbasket2=∑i,jwiwjρijσiσj\sigma_{\text{basket}}^2 = \sum_{i,j}w_iw_j\rho_{ij}\sigma_i\sigma_jσbasket2​=∑i,j​wi​wj​ρij​σi​σj​. Lower correlation →\to→ lower basket vol →\to→ basket options are cheaper. This is the mathematical basis of the diversification benefit.

8.7 Itô's product rule in ddd dimensions​

For two Itô processes XXX and YYY with possibly non-zero cross-variation:

d(XY)=X dY+Y dX+d[X,Y].d(XY) = X\,dY + Y\,dX + d[X,Y].d(XY)=XdY+YdX+d[X,Y].

For X=S1X = S^1X=S1, Y=S2Y = S^2Y=S2 with d[S1,S2]=ρσ1σ2S1S2 dtd[S^1,S^2] = \rho\sigma_1\sigma_2 S^1 S^2\,dtd[S1,S2]=ρσ1​σ2​S1S2dt:

d(S1S2)=S2 dS1+S1 dS2+ρσ1σ2S1S2 dt.d(S^1 S^2) = S^2\,dS^1 + S^1\,dS^2 + \rho\sigma_1\sigma_2 S^1 S^2\,dt.d(S1S2)=S2dS1+S1dS2+ρσ1​σ2​S1S2dt.

The extra term ρσ1σ2S1S2 dt\rho\sigma_1\sigma_2 S^1 S^2\,dtρσ1​σ2​S1S2dt is the stochastic correction from the cross-variation. It modifies the drift of the product process.

8.8 Multi-dimensional Girsanov​

For a ddd-dimensional BM W\mathbf WW under P\mathbb PP and adapted process θ=(θ1,…,θd)\boldsymbol\theta = (\theta^1,\ldots,\theta^d)θ=(θ1,…,θd), the stochastic exponential is:

ZT=exp⁡ ⁣(∑i∫0Tθsi dWsi−12∑i∫0T(θsi)2 ds).Z_T = \exp\!\left(\sum_i\int_0^T\theta_s^i\,dW_s^i - \tfrac12\sum_i\int_0^T(\theta_s^i)^2\,ds\right).ZT​=exp(i∑​∫0T​θsi​dWsi​−21​i∑​∫0T​(θsi​)2ds).

Under Q\mathbb QQ with dQ/dP=ZTdQ/dP = Z_TdQ/dP=ZT​:

W~ti=Wti−∫0tθsi ds\widetilde W_t^i = W_t^i - \int_0^t\theta_s^i\,dsWti​=Wti​−∫0t​θsi​ds

is a ddd-dimensional Q\mathbb QQ-BM.

In the multi-asset Black–Scholes model, the market prices of risk θ=((μ1−r)/σ1,…,(μd−r)/σd)\boldsymbol\theta = ((\mu_1-r)/\sigma_1, \ldots, (\mu_d-r)/\sigma_d)θ=((μ1​−r)/σ1​,…,(μd​−r)/σd​) are used to transform P\mathbb PP to Q\mathbb QQ.

8.9 Worked example: spread option​

A spread option pays (ST1−ST2−K)+(S_T^1 - S_T^2 - K)^+(ST1​−ST2​−K)+. Under Q\mathbb QQ:

log⁡(STi/S0i)∼N ⁣((r−12σi2)T,σi2T),\log(S_T^i/S_0^i) \sim N\!\left((r-\tfrac12\sigma_i^2)T, \sigma_i^2 T\right),log(STi​/S0i​)∼N((r−21​σi2​)T,σi2​T),

and the correlation is Corr(log⁡ST1,log⁡ST2)=ρ\text{Corr}(\log S_T^1,\log S_T^2) = \rhoCorr(logST1​,logST2​)=ρ.

No closed-form Black–Scholes formula exists for the spread. The Margrabe formula gives the price of an exchange option (ST1−ST2)+(S_T^1 - S_T^2)^+(ST1​−ST2​)+ with K=0K=0K=0:

Margrabe=S01N(d1)−S02N(d2),\text{Margrabe} = S_0^1 N(d_1) - S_0^2 N(d_2),Margrabe=S01​N(d1​)−S02​N(d2​), d1=log⁡(S01/S02)+12σ2TσT,d2=d1−σT,σ2=σ12+σ22−2ρσ1σ2.d_1 = \frac{\log(S_0^1/S_0^2) + \frac12\sigma^2 T}{\sigma\sqrt{T}}, \quad d_2 = d_1 - \sigma\sqrt{T}, \quad \sigma^2 = \sigma_1^2 + \sigma_2^2 - 2\rho\sigma_1\sigma_2.d1​=σT​log(S01​/S02​)+21​σ2T​,d2​=d1​−σT​,σ2=σ12​+σ22​−2ρσ1​σ2​.

The effective volatility σ\sigmaσ is the volatility of the ratio S1/S2S^1/S^2S1/S2.

8.10 Problems​

Problem 1: Quadratic variation of a linear combination

Let Xt=aWt1+bWt2X_t = aW_t^1 + bW_t^2Xt​=aWt1​+bWt2​ with d[W1,W2]=ρ dtd[W^1,W^2] = \rho\,dtd[W1,W2]=ρdt. Find [X]t[X]_t[X]t​.

Problem 2: Itô for $f(X,Y) = XY$

Let dX=σX dW1dX = \sigma_X\,dW^1dX=σX​dW1 and dY=σY(ρ dW1+1−ρ2 dW2)dY = \sigma_Y(\rho\,dW^1 + \sqrt{1-\rho^2}\,dW^2)dY=σY​(ρdW1+1−ρ2​dW2). Compute d(XY)d(XY)d(XY) and identify the extra drift term.

Problem 3: Log of correlated GBM

For two correlated GBMs as above, compute d(log⁡S1/S2)d(\log S^1/S^2)d(logS1/S2). This is the dynamics of the log spread. What does it mean for ρ=1\rho=1ρ=1?

Problem 4: Margrabe check

Verify that the Margrabe formula satisfies put-call parity: (ST1−ST2)+−(ST2−ST1)+=ST1−ST2(S_T^1 - S_T^2)^+ - (S_T^2 - S_T^1)^+ = S_T^1 - S_T^2(ST1​−ST2​)+−(ST2​−ST1​)+=ST1​−ST2​.

8.11 Selected solutions​

Solution 1

[X]t=a2[W1]t+2ab[W1,W2]t+b2[W2]t=a2t+2abρt+b2t=(a2+2abρ+b2)t[X]_t = a^2[W^1]_t + 2ab[W^1,W^2]_t + b^2[W^2]_t = a^2 t + 2ab\rho t + b^2 t = (a^2 + 2ab\rho + b^2)t[X]t​=a2[W1]t​+2ab[W1,W2]t​+b2[W2]t​=a2t+2abρt+b2t=(a2+2abρ+b2)t.

Solution 2

Using Itô's formula for the product:

d(XY)=X dY+Y dX+d[X,Y],d(XY) = X\,dY + Y\,dX + d[X,Y],d(XY)=XdY+YdX+d[X,Y],

where d[X,Y]=σXσYρ dtd[X,Y] = \sigma_X\sigma_Y\rho\,dtd[X,Y]=σX​σY​ρdt (only the dW1dW^1dW1 components contribute to cross-variation). Therefore:

d(XY)=XσY(ρ dW1+1−ρ2 dW2)+YσX dW1+σXσYρ dt.d(XY) = X\sigma_Y(\rho\,dW^1+\sqrt{1-\rho^2}\,dW^2) + Y\sigma_X\,dW^1 + \sigma_X\sigma_Y\rho\,dt.d(XY)=XσY​(ρdW1+1−ρ2​dW2)+YσX​dW1+σX​σY​ρdt.

The extra drift σXσYρ dt\sigma_X\sigma_Y\rho\,dtσX​σY​ρdt appears only because of correlation.

Solution 3

Let Rt=St1/St2R_t = S_t^1/S_t^2Rt​=St1​/St2​. By Itô's quotient rule (which follows from the multi-dimensional formula):

dlog⁡Rt=dlog⁡St1−dlog⁡St2=(μ1−μ2) dt+(σ12−ρσ1σ2) dt+σ1 dW1−σ2ρ dW1−σ21−ρ2 dW2.d\log R_t = d\log S_t^1 - d\log S_t^2 = (\mu_1-\mu_2)\,dt + (\sigma_1^2-\rho\sigma_1\sigma_2)\,dt + \sigma_1\,dW^1 - \sigma_2\rho\,dW^1 - \sigma_2\sqrt{1-\rho^2}\,dW^2.dlogRt​=dlogSt1​−dlogSt2​=(μ1​−μ2​)dt+(σ12​−ρσ1​σ2​)dt+σ1​dW1−σ2​ρdW1−σ2​1−ρ2​dW2.

More cleanly: dlog⁡R=(μ1−μ2−12σeff2) dt+σeff dW^d\log R = (\mu_1-\mu_2-\frac12\sigma_{\text{eff}}^2)\,dt + \sigma_{\text{eff}}\,d\hat WdlogR=(μ1​−μ2​−21​σeff2​)dt+σeff​dW^ where σeff2=σ12−2ρσ1σ2+σ22\sigma_{\text{eff}}^2 = \sigma_1^2-2\rho\sigma_1\sigma_2+\sigma_2^2σeff2​=σ12​−2ρσ1​σ2​+σ22​. For ρ=1\rho=1ρ=1 and σ1=σ2\sigma_1=\sigma_2σ1​=σ2​: σeff=0\sigma_{\text{eff}}=0σeff​=0, and log⁡R\log RlogR is deterministic — the ratio S1/S2S^1/S^2S1/S2 is non-random.
