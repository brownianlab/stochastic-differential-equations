# Stochastic Differential Equations  
### *A First-Principles Approach to Stochastic Differential Equations and Quantitative Finance*

🌐 **Live Site:** https://brownianlab.github.io/stochastic-differential-equations/

---

## 🧭 Overview

This project is a **modern, web-native textbook on stochastic differential equations (SDEs)** designed for graduate students, quantitative researchers, and practitioners.

Unlike traditional notes or static PDFs, this book is:

- Built from first principles  
- Mathematically rigorous  
- Geometrically intuitive  
- Deeply connected to quantitative finance  

Stochastic differential equations model systems driven by randomness and are central to fields such as finance, physics, and control theory.

---

## 🎯 Philosophy

This book is built around three pillars:

### 1. Mathematical Rigor
- Measure-theoretic probability  
- Filtrations and martingales  
- $L^2$ constructions  
- Existence and uniqueness of SDEs  

### 2. Geometric Intuition
- Brownian motion as a path-space object  
- Quadratic variation as intrinsic geometry  
- Covariance kernels as structure  

### 3. Quantitative Finance
- Trading strategies as stochastic integrands  
- P&L as Itô integrals  
- Pricing as martingale theory
