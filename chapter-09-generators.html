Chapter 9 — Diffusions and Generators

Guiding question

Given an SDE dX=b(X) dt+σ(X) dWdX = b(X)\,dt + \sigma(X)\,dWdX=b(X)dt+σ(X)dW, is there a single operator that encodes everything about how smooth functions evolve under XXX? How does this operator connect SDEs to partial differential equations?

The infinitesimal generator L\mathcal LL is the differential operator that describes the local behavior of a diffusion process. It packages Itô's formula into a single operator, and its study bridges stochastic analysis and classical analysis. The generator is the stochastic analogue of the derivative — it measures how fast the expected value of a function changes along the process.

9.1 The infinitesimal generator: definition​

Let XXX be the strong solution of dXt=b(Xt) dt+σ(Xt) dWtdX_t = b(X_t)\,dt + \sigma(X_t)\,dW_tdXt​=b(Xt​)dt+σ(Xt​)dWt​. For a smooth function f:R→Rf:\mathbb R\to\mathbb Rf:R→R with compact support, define:

Lf(x)=lim⁡t↓0Ex[f(Xt)]−f(x)t,\mathcal L f(x) = \lim_{t\downarrow 0}\frac{\mathbb E^x[f(X_t)] - f(x)}{t},Lf(x)=t↓0lim​tEx[f(Xt​)]−f(x)​,

where Ex[⋅]=E[⋅∣X0=x]\mathbb E^x[\cdot] = \mathbb E[\cdot\mid X_0 = x]Ex[⋅]=E[⋅∣X0​=x].

By Itô's formula, the limit exists and equals:

Lf(x)=b(x)f′(x)+12σ(x)2f′′(x).\boxed{\mathcal L f(x) = b(x)f'(x) + \tfrac12\sigma(x)^2 f''(x).}Lf(x)=b(x)f′(x)+21​σ(x)2f′′(x).​
Derivation from Itô's formula

By Itô's formula with f∈C2f\in C^2f∈C2:

f(Xt)=f(x)+∫0t[b(Xs)f′(Xs)+12σ2(Xs)f′′(Xs)] ds+∫0tσ(Xs)f′(Xs) dWs.f(X_t) = f(x) + \int_0^t [b(X_s)f'(X_s) + \tfrac12\sigma^2(X_s)f''(X_s)]\,ds + \int_0^t\sigma(X_s)f'(X_s)\,dW_s.f(Xt​)=f(x)+∫0t​[b(Xs​)f′(Xs​)+21​σ2(Xs​)f′′(Xs​)]ds+∫0t​σ(Xs​)f′(Xs​)dWs​.

Taking expectations (the stochastic integral has zero expectation):

Ex[f(Xt)]=f(x)+Ex ⁣[∫0tLf(Xs) ds].\mathbb E^x[f(X_t)] = f(x) + \mathbb E^x\!\left[\int_0^t\mathcal L f(X_s)\,ds\right].Ex[f(Xt​)]=f(x)+Ex[∫0t​Lf(Xs​)ds].

Dividing by ttt and taking t→0t\to 0t→0 (using Xs→xX_s\to xXs​→x and continuity of Lf\mathcal LfLf):

lim⁡t→0Ex[f(Xt)]−f(x)t=Lf(x).\lim_{t\to 0}\frac{\mathbb E^x[f(X_t)]-f(x)}{t} = \mathcal L f(x).t→0lim​tEx[f(Xt​)]−f(x)​=Lf(x).

LBMf=12f′′.\mathcal L_{\rm BM} f = \tfrac12 f''.LBM​f=21​f′′.

This is 12\frac1221​ the Laplacian (or the heat operator in one dimension).

9.3 Dynkin's formula​

Dynkin's formula

Let τ\tauτ be a stopping time with Ex[τ]<∞\mathbb E^x[\tau]<\inftyEx[τ]<∞ and f∈Dom(L)f\in\text{Dom}(\mathcal L)f∈Dom(L) (the domain of the generator). Then

Ex[f(Xτ)]=f(x)+Ex ⁣[∫0τLf(Xs) ds].\mathbb E^x[f(X_\tau)] = f(x) + \mathbb E^x\!\left[\int_0^\tau \mathcal L f(X_s)\,ds\right].Ex[f(Xτ​)]=f(x)+Ex[∫0τ​Lf(Xs​)ds].
Proof via optional stopping

The process Mt=f(Xt)−f(x)−∫0tLf(Xs) dsM_t = f(X_t) - f(x) - \int_0^t\mathcal L f(X_s)\,dsMt​=f(Xt​)−f(x)−∫0t​Lf(Xs​)ds is a local martingale (by Itô's formula). Under appropriate integrability, the optional stopping theorem applies at τ\tauτ: Ex[Mτ]=0\mathbb E^x[M_\tau]=0Ex[Mτ​]=0, which is Dynkin's formula.

Generator L = ½∂²/∂x² for Brownian motion: Dynkin's formula
Dynkin's formulaE[W_t² | W₀=x] = x² + t (Lf = 1)
Dynkin's formula: E[f(W_t)|W₀=x] = f(x) + t·Lf(x) + O(t²). The generator L = ½∂² measures the instantaneous rate of change of E[f(W_t)] at t=0. This connects martingale theory to PDEs: if M_t = f(W_t) − ∫₀ᵗ Lf(W_s)ds is a martingale, then Lf = 0 characterizes harmonic functions.

9.4 Harmonic functions​

A function fff is L\mathcal LL-harmonic on a domain DDD if Lf=0\mathcal L f = 0Lf=0 on DDD.

Mean value property for diffusions

If Lf=0\mathcal L f = 0Lf=0 on DDD and τD=inf⁡{t:Xt∉D}\tau_D = \inf\{t: X_t\notin D\}τD​=inf{t:Xt​∈/D} is the first exit time from DDD (with Ex[τD]<∞\mathbb E^x[\tau_D]<\inftyEx[τD​]<∞), then

f(x)=Ex[f(XτD)].f(x) = \mathbb E^x[f(X_{\tau_D})].f(x)=Ex[f(XτD​​)].

The value at any interior point equals the expected boundary value.

Proof

By Dynkin's formula: Ex[f(XτD)]=f(x)+Ex[∫0τDLf(Xs) ds]=f(x)\mathbb E^x[f(X_{\tau_D})] = f(x) + \mathbb E^x[\int_0^{\tau_D}\mathcal L f(X_s)\,ds] = f(x)Ex[f(XτD​​)]=f(x)+Ex[∫0τD​​Lf(Xs​)ds]=f(x), since Lf=0\mathcal L f = 0Lf=0.

Diffusions average over their domain

For ordinary Brownian motion, Lf=12f′′=0\mathcal L f = \frac12f''=0Lf=21​f′′=0 means fff is linear (in 1D). The mean value property says: the value of a linear function at any point equals its average on any symmetric interval. For multidimensional BM, harmonic functions satisfy the classical mean value property of harmonic analysis.

For diffusions with drift and varying diffusion, "harmonic" is with respect to the weighted operator b⋅∇+12σ2Δb\cdot\nabla + \frac12\sigma^2\Deltab⋅∇+21​σ2Δ — the natural geometry determined by the SDE.

9.5 The Kolmogorov equations​

The generator connects SDEs to two classical PDEs.

Forward (Fokker–Planck) equation. The probability density p(t,y;0,x)=∂yPx(Xt≤y)p(t,y;0,x) = \partial_y\mathbb P^x(X_t\le y)p(t,y;0,x)=∂y​Px(Xt​≤y) satisfies the PDE (written for the yyy-variable):

∂tp=L∗p,\partial_t p = \mathcal L^* p,∂t​p=L∗p,

where L∗\mathcal L^*L∗ is the adjoint operator:

L∗p=−∂y(b(y)p)+12∂yy(σ2(y)p).\mathcal L^* p = -\partial_y(b(y)p) + \tfrac12\partial_{yy}(\sigma^2(y)p).L∗p=−∂y​(b(y)p)+21​∂yy​(σ2(y)p).

This describes how the probability mass flows forward in time.

Backward (Kolmogorov backward) equation. The function u(t,x)=Ex[f(XT)∣Xt=x]u(t,x) = \mathbb E^x[f(X_T)\mid X_t = x]u(t,x)=Ex[f(XT​)∣Xt​=x] satisfies the PDE (written for the xxx-variable):

∂tu+Lxu=0,u(T,x)=f(x).\partial_t u + \mathcal L_x u = 0,\qquad u(T,x) = f(x).∂t​u+Lx​u=0,u(T,x)=f(x).

The subscript xxx means L\mathcal LL acts on the spatial variable xxx, with ttt as a parameter.

Forward vs backward: two perspectives on the same dynamics

The forward equation tracks the evolving probability distribution of XtX_tXt​. The backward equation tracks the conditional expectation of a functional, running time backward from the terminal condition.

In option pricing:

  • Forward equation = time-evolution of the stock price density (used in local volatility calibration).
  • Backward equation = the option price PDE (Black–Scholes, Feynman–Kac).

Both encode the same SDE; the difference is which variable (current state vs future payoff) is being tracked.

9.6 Generators in ddd dimensions​

For the ddd-dimensional SDE dX=b(X) dt+σ(X) dWd\mathbf X = \mathbf b(\mathbf X)\,dt + \boldsymbol\sigma(\mathbf X)\,d\mathbf WdX=b(X)dt+σ(X)dW, the generator is:

Lf(x)=∑ibi(x) ∂if(x)+12∑i,j(σσ⊤)ij(x) ∂ijf(x).\mathcal L f(\mathbf x) = \sum_i b_i(\mathbf x)\,\partial_i f(\mathbf x) + \tfrac12\sum_{i,j}(\sigma\sigma^\top)_{ij}(\mathbf x)\,\partial_{ij}f(\mathbf x).Lf(x)=i∑​bi​(x)∂i​f(x)+21​i,j∑​(σσ⊤)ij​(x)∂ij​f(x).

The matrix A=σσ⊤A = \sigma\sigma^\topA=σσ⊤ is the diffusion matrix. The generator is:

L=b⋅∇+12tr(A ∇2).\mathcal L = \mathbf b\cdot\nabla + \tfrac12\text{tr}(A\,\nabla^2).L=b⋅∇+21​tr(A∇2).

For A=IA = IA=I and b=0\mathbf b = 0b=0: L=12Δ\mathcal L = \frac12\DeltaL=21​Δ (half-Laplacian).

Generator of GBM in finance

For GBM dS=rS dt+σS dWdS = rS\,dt + \sigma S\,dWdS=rSdt+σSdW (risk-neutral), the generator is:

LBS=rS ∂S+12σ2S2 ∂SS.\mathcal L_{\rm BS} = rS\,\partial_S + \tfrac12\sigma^2 S^2\,\partial_{SS}.LBS​=rS∂S​+21​σ2S2∂SS​.

The Black–Scholes PDE is ∂tf+LBSf=rf\partial_t f + \mathcal L_{\rm BS} f = rf∂t​f+LBS​f=rf, i.e.,

(∂t+LBS−r)f=0.(\partial_t + \mathcal L_{\rm BS} - r)f = 0.(∂t​+LBS​−r)f=0.

The operator LBS−r\mathcal L_{\rm BS} - rLBS​−r is the Black–Scholes operator: its null space consists of correctly priced option prices. Adding rrr on the right reflects discounting at the risk-free rate.
