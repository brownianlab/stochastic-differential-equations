Chapter 10 — The Feynman–Kac Formula

Guiding question

Every PDE of the form ∂tu+Lu−cu=−f\partial_t u + \mathcal L u - c u = -f∂t​u+Lu−cu=−f has a solution that can be written as a conditional expectation. What is the precise connection, and how does it make numerical pricing by Monte Carlo and PDE methods equivalent?

The Feynman–Kac formula is one of the deepest results connecting probability and analysis. It says: the solution to a certain class of backward parabolic PDEs is a conditional expectation of a functional of a diffusion. This has two directions of impact:

  • Analytical: hard expectations become tractable PDEs.
  • Probabilistic: hard PDEs become tractable Monte Carlo simulations.

In finance, it is the rigorous foundation behind "price = expectation."

10.1 Setup​

Fix a terminal time T>0T > 0T>0 and a diffusion:

dXt=b(t,Xt) dt+σ(t,Xt) dWt.dX_t = b(t,X_t)\,dt + \sigma(t,X_t)\,dW_t.dXt​=b(t,Xt​)dt+σ(t,Xt​)dWt​.

Define the Feynman–Kac functional:

u(t,x)=E ⁣[exp⁡ ⁣(−∫tTc(s,Xs) ds)g(XT)+∫tTexp⁡ ⁣(−∫tsc(r,Xr) dr)f(s,Xs) ds ∣ Xt=x].u(t,x) = \mathbb E\!\left[\exp\!\left(-\int_t^T c(s,X_s)\,ds\right)g(X_T) + \int_t^T\exp\!\left(-\int_t^s c(r,X_r)\,dr\right)f(s,X_s)\,ds\ \Bigg|\ X_t = x\right].u(t,x)=E[exp(−∫tT​c(s,Xs​)ds)g(XT​)+∫tT​exp(−∫ts​c(r,Xr​)dr)f(s,Xs​)ds ​ Xt​=x].

Here:

  • ggg: terminal payoff
  • fff: running payoff (or source term)
  • ccc: discount rate (or killing rate)

10.2 The Feynman–Kac theorem​

Feynman–Kac formula

Under suitable regularity conditions, the function u(t,x)u(t,x)u(t,x) defined above is the unique classical solution to the backward PDE:

∂tu+b(t,x) ∂xu+12σ(t,x)2 ∂xxu−c(t,x) u+f(t,x)=0,\partial_t u + b(t,x)\,\partial_x u + \tfrac12\sigma(t,x)^2\,\partial_{xx}u - c(t,x)\,u + f(t,x) = 0,∂t​u+b(t,x)∂x​u+21​σ(t,x)2∂xx​u−c(t,x)u+f(t,x)=0,

on [0,T)×R[0,T)\times\mathbb R[0,T)×R, with terminal condition u(T,x)=g(x)u(T,x) = g(x)u(T,x)=g(x).

Proof via Itô's formula

Define Yt=e−∫0tc(s,Xs) dsu(t,Xt)+∫0te−∫0sc f(s,Xs) dsY_t = e^{-\int_0^t c(s,X_s)\,ds}u(t,X_t) + \int_0^t e^{-\int_0^s c}\,f(s,X_s)\,dsYt​=e−∫0t​c(s,Xs​)dsu(t,Xt​)+∫0t​e−∫0s​cf(s,Xs​)ds.

We want to show YtY_tYt​ is a martingale. By Itô's formula applied to v(t,x)=e−∫0tc dsu(t,x)v(t,x) = e^{-\int_0^t c\,ds}u(t,x)v(t,x)=e−∫0t​cdsu(t,x):

dYt=e−∫0tc ds ⁣[(∂tu+b∂xu+12σ2∂xxu−cu+f) dt+σ∂xu dWt].dY_t = e^{-\int_0^t c\,ds}\!\left[(\partial_t u + b\partial_x u + \tfrac12\sigma^2\partial_{xx}u - cu + f)\,dt + \sigma\partial_x u\,dW_t\right].dYt​=e−∫0t​cds[(∂t​u+b∂x​u+21​σ2∂xx​u−cu+f)dt+σ∂x​udWt​].

If uuu solves the PDE, the dtdtdt coefficient vanishes, leaving dYt=(pure stochastic integral)dY_t = (\text{pure stochastic integral})dYt​=(pure stochastic integral). A stochastic integral is a local martingale. Under integrability, YtY_tYt​ is a true martingale.

Terminal condition: YT=e−∫0Tc dsg(XT)+∫0Te−∫0scf(s,Xs) dsY_T = e^{-\int_0^T c\,ds}g(X_T) + \int_0^T e^{-\int_0^s c}f(s,X_s)\,dsYT​=e−∫0T​cdsg(XT​)+∫0T​e−∫0s​cf(s,Xs​)ds.

At time ttt: E[YT∣Ft]=Yt\mathbb E[Y_T\mid\mathcal F_t] = Y_tE[YT​∣Ft​]=Yt​ (martingale). Rewriting gives u(t,Xt)=E[…∣Xt]u(t,X_t) = \mathbb E[\ldots\mid X_t]u(t,Xt​)=E[…∣Xt​].

10.3 The pure terminal payoff case​

In the simplest case c=0c = 0c=0, f=0f = 0f=0, the Feynman–Kac formula reduces to:

u(t,x)=E[g(XT)∣Xt=x],u(t,x) = \mathbb E[g(X_T)\mid X_t = x],u(t,x)=E[g(XT​)∣Xt​=x],

which solves:

∂tu+b(t,x)∂xu+12σ(t,x)2∂xxu=0,u(T,x)=g(x).\partial_t u + b(t,x)\partial_x u + \tfrac12\sigma(t,x)^2\partial_{xx}u = 0,\qquad u(T,x) = g(x).∂t​u+b(t,x)∂x​u+21​σ(t,x)2∂xx​u=0,u(T,x)=g(x).

For pure Brownian motion (b=0b=0b=0, σ=1\sigma=1σ=1), this is the heat equation ∂tu=−12∂xxu\partial_t u = -\frac12\partial_{xx}u∂t​u=−21​∂xx​u (note the sign: running backward from TTT to 000). The solution is convolution with the Gaussian kernel:

u(0,x)=12πT∫−∞∞g(y) e−(x−y)2/(2T) dy.u(0,x) = \frac{1}{\sqrt{2\pi T}}\int_{-\infty}^\infty g(y)\,e^{-(x-y)^2/(2T)}\,dy.u(0,x)=2πT​1​∫−∞∞​g(y)e−(x−y)2/(2T)dy.

This is exactly the smoothing property of the heat equation — the Brownian motion "averages" the terminal payoff over Gaussian fluctuations.

10.4 Discounted terminal payoff​

With discount rate c=rc = rc=r (constant) and f=0f=0f=0:

u(t,x)=e−r(T−t)E[g(XT)∣Xt=x].u(t,x) = e^{-r(T-t)}\mathbb E[g(X_T)\mid X_t = x].u(t,x)=e−r(T−t)E[g(XT​)∣Xt​=x].

The PDE becomes:

∂tu+b∂xu+12σ2∂xxu−ru=0.\partial_t u + b\partial_x u + \tfrac12\sigma^2\partial_{xx}u - ru = 0.∂t​u+b∂x​u+21​σ2∂xx​u−ru=0.

For GBM under Q\mathbb QQ (b=rxb = rxb=rx, σ=σx\sigma = \sigma xσ=σx): this is precisely the Black–Scholes PDE. The Feynman–Kac formula proves that the Black–Scholes price equals the risk-neutral discounted expectation.

Every pricing problem can be attacked from either side: solve the PDE analytically, or simulate the SDE by Monte Carlo.

10.5 Worked examples​

Example 1: European call option​

X=SX = SX=S follows GBM under Q\mathbb QQ, g(S)=(S−K)+g(S) = (S-K)^+g(S)=(S−K)+, c=rc = rc=r.

Feynman–Kac: C(t,S)=e−r(T−t)EQ[(ST−K)+∣St=S]C(t,S) = e^{-r(T-t)}\mathbb E^{\mathbb Q}[(S_T-K)^+\mid S_t = S]C(t,S)=e−r(T−t)EQ[(ST​−K)+∣St​=S].

This expectation evaluates to the Black–Scholes formula (Chapter 7).

Example 2: Zero-coupon bond in CIR model​

rtr_trt​ follows CIR (dr=κ(θ−r) dt+σr dWdr = \kappa(\theta-r)\,dt + \sigma\sqrt{r}\,dWdr=κ(θ−r)dt+σr​dW). The zero-coupon bond price is:

P(t,r)=E ⁣[exp⁡ ⁣(−∫tTrs ds)∣rt=r].P(t,r) = \mathbb E\!\left[\exp\!\left(-\int_t^T r_s\,ds\right)\Bigg| r_t = r\right].P(t,r)=E[exp(−∫tT​rs​ds)​rt​=r].

Feynman–Kac says PPP solves:

∂tP+κ(θ−r)∂rP+12σ2r ∂rrP−rP=0,P(T,r)=1.\partial_t P + \kappa(\theta-r)\partial_r P + \tfrac12\sigma^2 r\,\partial_{rr}P - rP = 0, \quad P(T,r) = 1.∂t​P+κ(θ−r)∂r​P+21​σ2r∂rr​P−rP=0,P(T,r)=1.

Example 3: Running maximum​

Let MT=max⁡0≤s≤TWsM_T = \max_{0\le s\le T}W_sMT​=max0≤s≤T​Ws​. Can we find E[f(MT)]\mathbb E[f(M_T)]E[f(MT​)]?

10.6 The Kolmogorov backward equation as a special case​

For c=0c=0c=0, f=0f=0f=0, and g=1(−∞,y]g = \mathbf 1_{(-\infty,y]}g=1(−∞,y]​ (cumulative distribution), Feynman–Kac gives:

u(t,x)=P(XT≤y∣Xt=x).u(t,x) = \mathbb P(X_T \le y\mid X_t = x).u(t,x)=P(XT​≤y∣Xt​=x).

This solves the Kolmogorov backward equation ∂tu+Lxu=0\partial_t u + \mathcal L_x u = 0∂t​u+Lx​u=0. Setting t=0t=0t=0 gives the transition probability P(XT≤y∣X0=x)\mathbb P(X_T\le y\mid X_0=x)P(XT​≤y∣X0​=x) — the fundamental solution of the backward equation.

10.7 Monte Carlo versus PDE: two algorithms​

Monte Carlo (probabilistic side):

  1. Simulate NNN paths of XXX from xxx to time TTT using Euler–Maruyama.
  2. Compute g(XT(k))g(X_T^{(k)})g(XT(k)​) for each path kkk.
  3. Estimate u(0,x)≈1N∑kg(XT(k))u(0,x)\approx \frac{1}{N}\sum_k g(X_T^{(k)})u(0,x)≈N1​∑k​g(XT(k)​).

Error: O(1/N)O(1/\sqrt{N})O(1/N​) — statistical, independent of dimension.

PDE solver (analytical side):

  1. Discretize the PDE on a grid (ti,xj)(t_i, x_j)(ti​,xj​).
  2. Apply finite differences or finite elements.
  3. March backward from TTT to 000.

Error: O(Δt+Δx2)O(\Delta t + \Delta x^2)O(Δt+Δx2) — deterministic, but grid size explodes in high dimensions (curse of dimensionality).

Feynman–Kac guarantees both methods converge to the same answer.

When to use Monte Carlo vs PDE

Use PDE when: 1D or 2D problem (e.g., European option on one stock), high accuracy needed, Greeks required analytically (differentiate PDE solution), early exercise (American options via free boundary PDE).

Use Monte Carlo when: High-dimensional problem (basket, path-dependent), flexible payoff structure, convergence guarantee regardless of dimension, embarrassingly parallelizable.

Dimension d≥4d\ge 4d≥4: Monte Carlo dominates. Dimension d≤3d\le 3d≤3: PDE methods are often faster and more precise.
